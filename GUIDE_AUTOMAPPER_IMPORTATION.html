1. Introduction et Concept

Qu'est-ce que l'Automapper?

L'Automapper est un système intelligent qui détecte automatiquement les colonnes d'un fichier importé (Excel, ODS, CSV) et les mappe aux champs du système sans intervention manuelle de l'utilisateur. Cela permet une importation rapide et fiable sans configuration préalable.

💡 Concept clé: "Write once, import anywhere"

Peu importe l'ordre des colonnes, leur noms exacts, ou les accents utilisés, le système trouvera toujours la bonne correspondance.

Bénéfices de l'Automapper

  • ✅ Simplicité: L'utilisateur n'a rien à configurer
  • ✅ Flexibilité: Accepte différents formats et conventions
  • ✅ Rapidité: Import en quelques secondes
  • ✅ Fiabilité: Détecte erreurs avant import
  • ✅ Intelligence: Suggestions IA intégrées
  • ✅ Robustesse: Gère les variantes (accents, casse, espaces)

2. Pourquoi l'Automapper?

Problème Sans Automapper

Sans automapper, chaque import de fichier nécessiterait:

  1. Examiner manuellement les colonnes
  2. Sélectionner la colonne source pour chaque champ
  3. Corriger les erreurs de mappage
  4. Tester avec les données
  5. Réimporter si erreur
⏱️ Temps gaspillé: 10-15 minutes par import

Solution Avec Automapper

Avec automapper:

  1. L'utilisateur sélectionne un fichier → automatique!
  2. Système détecte type de fichier (Turnover, Recap, Générique)
  3. Colonnes sont mappées automatiquement
  4. Données validées
  5. Suggestions IA affichées
  6. Import en 1 clic
⚡ Temps économisé: 5 secondes par import

4. Types de Fichiers Reconnus

Type 1: Turnover (Rotation du Personnel)

🏢 Format Turnover - Analyse des Départs

Utilisé pour importer les données de rotation du personnel, incluant les départs volontaires/involontaires, dates, raisons, etc.

Critères de Détection Turnover:

  • ✓ Contient la colonne Nom et Prénom
  • ✓ Minimum 4 champs de cette liste:
Mois Nom et Prénom Position / Poste Département / DEPT Date d'embauche Date de départ Ancienneté Genre Type d'organisation Collège Type d'effectif Motif de départ Cause de départ Cumul

Exemple de Fichier Turnover:

Mois Nom et Prénom Position Département Date d'embauche Date de départ
2026-04 Jean Dupont Manager Ventes 2020-01-15 2026-03-31
2026-04 Marie Martin Développeur IT 2022-06-01 2026-04-15

Type 2: Monthly Recap (Récapitulatif Mensuel)

📊 Format Récapitulatif - Heures et Absences

Utilisé pour importer les récapitulatifs mensuels incluant les heures normales, majorations et absences par employé.

Critères de Détection Récap:

  • ✓ Contient Matricule ET Nom & Prénom
  • ✓ Minimum 6 champs de cette liste:
Matricule Nom & Prénom / Nom et Prénom Régime Département (New) Type d'effectif Genre Date d'embauche H. T (Heures Normales) 25 % (Majoration 25%) 50 % (Majoration 50%) 100 % (Majoration 100%) H. NUIT (Heures de Nuit) ABS./jour (Absences par jour) ABS./h (Absences en heures)

Exemple de Fichier Monthly Recap:

Matricule Nom & Prénom Département H. T 25 % 50 % 100 % ABS./jour
EMP001 Jean Dupont Ventes 160 2 0 0 1
EMP002 Marie Martin IT 164 4 2 1 0

Type 3: Générique (Autre)

📋 Format Générique - Employés et Données

Utilisé pour les fichiers qui ne correspondent à aucun format spécialisé. Accepte les colonnes standards d'employés.

Champs Génériques Reconnus:

Employee ID / ID Employé / Matricule Name / Nom / Prénom Nom Department / Département / DEPT Position / Poste / Job Title Email / Mail Absence Days / Absences / Jours absence Overtime Hours / Heures supplémentaires / Overtime Weekly Hours / Heures hebdomadaires / Weekly Hours Status / Statut

5. Algorithme de Détection

Détection du Type de Fichier

Étape 1: Scan des En-têtes

L'algorithme scanne la première ligne de chaque feuille Excel pour identifier les en-têtes de colonne.

// Pseudo-code function detectFileType(workbook) { for (sheet in workbook.sheets) { rows = readRows(sheet) headerRow = findHeaderRow(rows) if (headerRow is Turnover format) { return 'turnover' } if (headerRow is Monthly Recap format) { return 'monthlyRecap' } } return 'generic' }

Étape 2: Détection Turnover

function detectTurnoverHeaderRow(rows) { expectedFields = normalize([ 'Mois', 'Nom et Prénom', 'Position', 'Département', ... ]) for (row in rows) { normalizedRow = normalize(row) matches = count(expectedFields in normalizedRow) if (matches >= 4 OR contains 'Nom et Prénom') { return row.index } } return -1 // Not found }

Étape 3: Détection Monthly Recap

function detectMonthlyRecapHeaderRow(rows) { for (row in rows) { normalizedRow = normalize(row) if (contains 'Matricule' AND contains 'Nom & Prénom' AND matches >= 6 expected fields) { return row.index } } return -1 }

6. Système de Normalisation

Pourquoi Normaliser?

Les fichiers peuvent avoir des variantes:

  • Casse différente: MATRICULE, Matricule, matricule
  • Accents: Département, Departement
  • Espaces: Nom et Prénom, NometPrénom, Nom et Prénom
  • Caractères: Nom et Prénom, Nom et Prenom

Processus de Normalisation

function normalize(value: string) { return value .toLowerCase() // Minuscules .normalize('NFD') // Décomposer accents .replace(/[\u0300-\u036f]/g, '') // Supprimer diacritiques .replace(/['']/g, "'") // Unifier apostrophes .trim() // Supprimer espaces }

HEURES heures ✅ Match

7. Processus de Mappage

Algorithme de Mappage Automatique

Une fois le type détecté et les en-têtes normalisés, le système mappe chaque champ système à une colonne source.

function autoMapColumns(sourceColumns: string[], fileType: string) { // Sélectionner liste de champs selon type systemFields = (fileType == 'turnover') ? turnoverFields : (fileType == 'monthlyRecap') ? monthlyRecapFields : genericFields; mapping = []; // Pour chaque champ système for (systemField in systemFields) { normalizedField = normalize(systemField); // Chercher colonne source correspondante matchedColumn = findBestMatch( normalizedField, sourceColumns ); // Ajouter au mappage mapping.push({ systemField: systemField, sourceColumn: matchedColumn || '' }); } return mapping; } function findBestMatch(normalizedField: string, sourceColumns: string[]): string { for (sourceCol in sourceColumns) { normalizedCol = normalize(sourceCol); // Deux critères de match: // 1. La colonne contient le champ // 2. Le champ contient la colonne if (normalizedCol.includes(normalizedField) || normalizedField.includes(normalizedCol)) { return sourceCol; // Return original name } } return null; }

Exemple Détaillé du Mappage

Fichier Source:

Colonnes: MOIS | NOM COMPLET | POSTE | DEPT | H_REGULIERE | HEURES_25PCT | ABS_JOURS

Processus de Mappage (Turnover):

# Champ Système Normalisé Colonnes Source Match Résultat
1 Mois mois mois, nom complet, poste... ✓ "mois" in "MOIS" → MOIS
2 Nom et Prénom nom et prenom mois, nom complet, poste... ✓ "nom et prenom" in "nom complet" → NOM COMPLET
3 Position position mois, nom complet, poste... ✓ "position" in "poste" → POSTE
4 Département departement mois, nom complet, poste... ✓ "departement" in "dept" → DEPT

8. Validation des Données

Validations Effectuées

Après le mappage, les données sont validées pour détecter les anomalies.

Règles de Validation

Champ Validation Exemple Erreur
Absence Days 0 ≤ value ≤ 365 ❌ -5 jours (négatif)
Overtime Hours 0 ≤ value ≤ 100 ❌ 200 heures (excessif)
Weekly Hours 0 ≤ value ≤ 60 ❌ 0 heures (valeur basse)
Name Non vide, min 2 chars ❌ "" (vide)
Email Format valide (regex) ❌ "invalid@" (format)
Date Format ISO ou valide ❌ "32/13/2026" (invalide)

Exemple de Validation

function validateData(rows: RawRow[]) { const errors: string[] = []; rows.forEach((row, idx) => { const absenceDays = parseFloat(row['Absence Days'] || '0'); const overtime = parseFloat(row['Overtime Hours'] || '0'); // Absence négative? if (absenceDays < 0) errors.push(`Ligne ${idx+2}: Absence négative (${absenceDays})`); // Overtime négatif? if (overtime < 0) errors.push(`Ligne ${idx+2}: Heures sup négatives (${overtime})`); // Absence irréaliste? if (absenceDays > 365) errors.push(`Ligne ${idx+2}: Absence irréaliste (${absenceDays} jours)`); // Heures excessives? if (overtime > 100) errors.push(`Ligne ${idx+2}: Heures sup excessives (${overtime}h)`); }); return errors; }

9. Suggestions IA

Vérifications IA Intégrées

Avant l'import, le système effectue des vérifications IA pour détecter les anomalies et donner des suggestions à l'utilisateur.

Types de Vérifications

1. Vérification des Colonnes Manquantes

Exemple:
Format Turnover détecté mais manquent:
"Date de départ, Ancienneté, Genre, Motif de départ"
Action: Avertissement utilisateur

2. Détection des Doublons

Exemple:
Doublons détectés:
"Jean Dupont" (2 fois), "Marie Martin" (3 fois)
Action: Suggestion de vérification

3. Validation des Domaines

Exemple:
Département non standard:
"Ressources Humanez" (au lieu de "Ressources Humaines")
Action: Suggestion de correction

4. Vérification des Formats

Exemple:
Format de date suspecte:
"2026/04/15" vs "15-04-2026"
Action: Alerte standardisation

Code des Suggestions IA

function runAIChecks(rows, cols, fileType) { const suggestions = []; // 1. Vérifier colonnes manquantes if (fileType === 'turnover') { const expectedFields = turnoverFields.map(normalize); const missingHeaders = turnoverFields.filter(field => !cols.some(col => normalize(col) === normalize(field)) ); if (missingHeaders.length) { suggestions.push( `Colonnes Turnover manquantes: ${missingHeaders.join(', ')}` ); } } // 2. Vérifier doublons const names = rows.map(r => r['Name'] || r['name']).filter(Boolean); const duplicates = names.filter((n, i) => names.indexOf(n) !== i); if (duplicates.length) { suggestions.push( `Doublons possibles: ${[...new Set(duplicates)].join(', ')}` ); } // 3. Vérifier domaines rows.forEach((row, idx) => { const dept = row['Department']; const standardDepts = ['RH', 'IT', 'Ventes', 'Finance', 'Support']; if (dept && !standardDepts.includes(dept)) { suggestions.push( `Ligne ${idx+2}: Département non standard "${dept}"` ); } }); return suggestions; }

11. Dépannage

Problème 1: Format Non Détecté

Symptôme: "Format Générique" au lieu de "Turnover" ou "Monthly Recap"
Causes possibles:
  • En-têtes mal orthographiés ou dans langue différente
  • Colonnes obligatoires manquantes
  • Format non standard
Solution:
  • Vérifier orthographe des colonnes (ex: "Nom et Prénom" pas "Noms et Prenoms")
  • S'assurer que colonnes clés sont présentes
  • Pour Turnover: avoir "Nom et Prénom" + min 4 champs
  • Pour Recap: avoir "Matricule" + "Nom & Prénom"

Problème 2: Colonnes Mal Mappées

Symptôme: Une colonne est mappée au mauvais champ
Causes possibles:
  • Deux colonnes contiennent des mots similaires
  • Normalisation crée une fausse correspondance
Solution:
  • Renommer la colonne pour être plus spécifique
  • Exemple: "Date_Depart_Réelle" au lieu de "Date_Depart"
  • Utiliser séparateurs distinctifs

Problème 3: Validation Échoue

Symptôme: Erreurs de validation (valeurs négatives, excessives)
Causes possibles:
  • Format de données incorrect
  • Unités différentes (heures vs minutes)
  • Valeurs par défaut/placeholder
Solution:
  • Corriger les valeurs dans le fichier source
  • S'assurer que "Absence Days" est en jours, pas heures
  • Supprimer les valeurs de test (-1, 9999, etc.)

Problème 4: Suggestions IA Incorrectes

Symptôme: L'IA suggère des colonnes manquantes qui ne sont pas nécessaires
Causes possibles:
  • Format simplifié (pas toutes les colonnes optionnelles)
  • Version différente du format
Solution:
  • Les suggestions IA sont à titre informatif
  • L'import fonctionnera même avec colonnes manquantes (elles auront valeur par défaut)
  • Ajouter les colonnes seulement si données disponibles

12. Bonnes Pratiques

Pour les Administrateurs HR

✅ À FAIRE:

  • Utiliser les en-têtes standards: "Nom et Prénom", "Matricule", "H. T"
  • Maintenir cohérence: Mêmes noms de colonnes à chaque export
  • Vérifier avant import: Lire les suggestions IA
  • Sauvegarder fichier source: Pour traçabilité
  • Importer régulièrement: Plutôt que accumuler données
  • Vérifier résultat: Consulter ImportHistory

❌ À ÉVITER:

  • ❌ Modifier l'ordre des colonnes sans raison
  • ❌ Utiliser des caractères spéciaux dans les en-têtes
  • ❌ Laisser des cellules vides (même si c'est "N/A")
  • ❌ Mélanger formats dans même fichier
  • ❌ Importer données sans valider d'abord
  • ❌ Utiliser espaces dans les noms de colonnes

Formats de Fichiers Recommandés

Format Recommandation Avantages Inconvénients
.xlsx ⭐⭐⭐ Recommandé Moderne, standard, multipage Peut être volumineux
.csv ⭐⭐ Alternatif Léger, universel Format limité, une feuille
.ods ⭐ OK Open source, multipage Moins courant
.xls ⭐ Basique Ancienne compatibilité Format ancien, limites

Étapes Avant l'Import

  1. Vérifier les en-têtes: Utiliser nomenclature standard
  2. Valider les données: Aucune cellule manquante
  3. Tester format: Ouvrir dans Excel pour vérifier
  4. Sauvegarder: Fichier source avant toute modification
  5. Préparer aperçu: Lire 2-3 lignes
  6. Documenter: Notes sur source des données

Étapes Après l'Import

  1. Vérifier résumé: Nombre de lignes importées
  2. Consulter history: Statut Success/Partial/Failed
  3. Valider données: Dashboard affiche les KPI correctement
  4. Tester fonctionnalités: Prédictions IA, exports
  5. Documenter: Date et nombre d'imports dans log
